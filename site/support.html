Support

Icy Weasel 1.0

A site doesn't work properly

Click the shield in the toolbar (or press Option-Command-P). From there you can, for that site only:

  • turn off ad blocking, if a page is missing content or a button does nothing;
  • switch JavaScript to Full speed, if a web app feels slow;
  • allow pop-ups, if a sign-in or payment window doesn't open.

Your other sites keep their full protection.

A YouTube ad got through

YouTube changes how it delivers ads every few weeks. Please report it so the fix can ship quickly.

Installing

Open the downloaded disk image and drag Icy Weasel into Applications. To remove it, drag it to the Bin; your history and settings are in Library/Containers/com.icyweasel.browser in your home folder.

Using the page assistant

Install Ollama, download a model (for example by running ollama pull qwen3:8b), then click the sparkle button in the toolbar. Everything runs on your Mac.

Report a problem or ask a question

Open an issue on GitHub. Include your macOS version, the Icy Weasel version (Icy Weasel menu, About Icy Weasel) and the address of the page if a site is involved.
